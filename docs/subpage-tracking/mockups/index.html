Subpage UI mockups

Four layout directions for surfacing per-path data on site.html. Each link opens a previewable mockup using the real theme CSS.

  • A — List below the grid
    Existing four-chart grid stays as-is; a ranked path table sits below it. Minimal change, scrollable.
  • B — Tile inside the grid
    Adds a fifth tile next to Time / Overview / Visits / Hourly. Everything on one screen but paths are cramped.
  • C — Site ⇄ Pages toggle
    Segmented control swaps the whole body between the existing site view and a full-width paths table with filter / sort.
  • D — Dedicated path drill page
    B-style compact list in the grid tile; each row opens path.html with the full chart set scoped to that path. Breadcrumb subheader shows the parent site.

See ui-mockups.md for the written summary and recommendation.
