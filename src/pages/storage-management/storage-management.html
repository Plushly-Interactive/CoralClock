Import / Export data

BiteGuard format

Back up your BiteGuard data or transfer it between installs. Includes all daily and hourly browsing stats and settings.

  • Active time per site
  • Visit counts per site
  • Audio time per site
  • Per subpage data
  • Site rules & limits
  • Settings

Time Tracker compatibility

Exchange data with the "Time Tracker - Web Habit Builder" extension (v). Not all data is compatible.

  • Active time per site (daily only)
  • Visit counts per site (daily only)
  • Audio time
  • Site rules
  • Settings

CSV / Spreadsheet

Export site stats as a CSV file, openable in any spreadsheet app. Times are in decimal minutes.

  • Active time per site (in minutes)
  • Audio time per site (in minutes)
  • Visit counts per site
  • Daily or hourly granularity (one button each)
  • Per subpage data
